Angular Playground

A hands-on tour of modern Angular (v21, with notes on the syntax still found in v19/v20 code). Each topic is its own page with live demos you can play with while reading the code next to it.

How to use it

  • Pick a topic in the sidebar. Topics are ordered: later ones build on earlier ones.
  • Every topic page is a list of demo cards: a title, a live demo, a short explanation and a box with tips and gotchas.
  • Open the topic's folder under src/app/topics/ side by side with the browser. Edits to templates and styles are applied instantly without losing the demo state.
  • The written companion is docs/ANGULAR_GUIDE.md in the repository.

What a demo card looks like

Sample: a signal counter

clicks is a signal(0). The template reads it with clicks(), and update() changes it, so Angular knows exactly which part of the view to refresh.

  • Signals are read by calling them: clicks(), not clicks.
  • Prefer update(fn) over set(clicks() + 1) when the new value depends on the old one.
